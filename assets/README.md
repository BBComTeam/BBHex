# Image notes / 图片说明

- `brand/`: BBHex's theme-aware logo artwork, supplied by BBCom Team.
- `screenshots/en-US/` and `screenshots/zh-CN/`: four 1920 × 1080 UI images per language, prepared for the 0.3.8 product listing. They show the actual application interface rendered in Edge with synthetic data and a deterministic native-API fixture bridge. They are illustrative interface renders, not captures of an installed native window.
- `features/`: frames from the 0.4.3 Chinese product demonstration. The interface regions were captured from a running BBHex Tauri application using real file operations and synthetic sample files, then enlarged and captioned for the demonstration. The sync-selection example compares float32 values 42.75 and 43.125. The ARM example decodes a Thumb LDR instruction and reads the file constant `0x12345678 / 305419896`.

The gallery spans different application revisions. Layout details may vary by release, theme, language and configuration. No user documents or production firmware are included.
